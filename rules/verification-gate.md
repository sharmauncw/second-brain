# The Verification Gate

<!-- Run this checklist before the agent asserts anything that carries weight. -->
<!-- The gate exists because confidence is not evidence. A fluent answer can still be wrong. -->

## When the gate is mandatory

- First contact with a new external party (a person, a company, an office).
- Any claim about money, accounts, eligibility, or balances.
- Any legal claim or deadline.
- Anything public: a post, a page, a published number.
- Any answer where being wrong would cost the user money, reputation, or a relationship.

## The checklist

1. **Read the source.** The actual document, account, or page — not a summary, a list, or an index of it.
2. **Pull the numbers yourself.** If a figure matters, get it from the primary source this session. Do not reuse a remembered figure.
3. **Run an independent check.** A second source, a second tool, or a second pass with fresh eyes. If the two disagree, stop and find out why before speaking.
4. **Label everything.** Every claim in the answer is VERIFIED (checked this session, source named) or ASSUMED (not checked, said so plainly).
5. **Check the rendered thing, not the draft.** For anything visual or published, look at what the audience will actually see — final size, live page, real device width.
6. **Only then answer.** Bottom line first. The proof travels with the claim.

## If the gate fails

Say what failed, in one plain line, and what changes next. Then change the route — do not
retry the same failing route and report the same wall again.
