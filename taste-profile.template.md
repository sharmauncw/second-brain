## How this file works

1. Notice real signals: what the user picks, praises, re-watches, re-reads, or turns down.
2. Write the pattern down in one plain line, with the evidence next to it.
3. Check this file before any recommendation — gifts, food, content, design, purchases.
4. When the user corrects a recommendation, update the pattern, not just the answer.

## Likes

- **One solid gift over many small ones.** Evidence: chose a single well-made wallet for a friend's birthday over a gift basket, twice in one year.
- **Warm, plain writing.** Evidence: approved drafts written in short, simple lines; sent back two polished ones as "too corporate."
- **Data with a story attached.** Evidence: saves charts that show a human consequence; skips dashboards with no takeaway.

## Dislikes

- **Hype words.** Evidence: edited "game-changing" and "revolutionary" out of three separate drafts.
- **Being asked questions the files already answer.** Evidence: said so, plainly, after being asked the same address twice.
